## 结论：有训练功能，且原生支持中文和英文

这是 **🐸 Coqui TTS**（原 Mozilla TTS），是一个完整的 TTS 训练/推理库，不只是推理工具。README 明确写了：

> 🛠️ Tools for training new models and fine-tuning existing models in any language.

并且源码里**已经内置了中文前端**：
- `TTS/tts/utils/text/phonemizers/zh_cn_phonemizer.py` —— 专门的中文（普通话）音素化器，`language = "zh-cn"`，能把"这是，样本中文。"转成音素。
- 英文是默认一等公民（LJSpeech、VCTK、Thorsten 等都是英文 recipe）。
- 端到端模型 **ⓍTTS v2 支持 16 种语言，含中文 `zh-cn`**；还有 Fairseq MMS 提供约 1100 种语言（含中文 `cmn`）的 VITS 模型。

## 但是，有前置条件（关键）

你不能直接把"一堆音频 + 一堆文本"丢进去就训练。需要满足：

**1. 音频和文本必须逐句对齐（最重要）**
TTS 训练要求"一条音频 clip ↔ 对应一句文本"。数据集格式是 LJSpeech 的 `metadata.txt`：
```
audio1|这是我的句子。|这是我的句子。
audio2|...|...
```
且音频推荐无损 `wav`。如果你现在是"长音频 + 对应长文本"，必须先做**切分与强制对齐**（用 Montreal Forced Aligner、强制对齐工具，把你工作区里就有 `MFA_tool` 相关目录，正好能用）。没有对齐，无法训练。

**2. 运行环境**
- Python >=3.9 且 <3.12（注意不支持 3.12+）
- PyTorch + CUDA（GPU 强烈建议；CPU 训练极慢，基本不现实）
- 项目在 Linux/Ubuntu 上安装最顺，Windows 有专门的[安装指南](https://stackoverflow.com/questions/66726331)（README 第 169 行）

**3. 选训练方式（决定了你需要多少数据）**

| 方式 | 需要的数据量 | 说明 |
|------|------|------|
| **ⓍTTS 声音克隆（纯推理）** | 几秒~几分钟参考音频 | 不需训练，给 `speaker_wav` + 文本即可说中文 |
| **ⓍTTS / YourTTS 微调 fine-tune** | 约 1–2 小时 | 用 `--restore_path` 加载预训练模型在你的数据上微调，最快出效果 |
| **从头训练 VITS / Glow-TTS / Tacotron2** | 数小时~数十小时 | 数据饥渴，需配 `vocoder`，工作量大 |

**4. 中文音素化的注意点**
`zh_cn_phonemizer.py` 里作者自己留了 TODO：*"someone with Mandarin knowledge should check this implementation"*（中文音素化实现待母语者校验）。所以中文效果可能不是最优。更稳妥的替代：用 `espeak-ng`（`espeak_wrapper.py` 支持 `zh`）或基于 Fairseq MMS 的 `cmn` 模型。

## 给你的实操建议（按"音频+文本"起步）

如果你目标是"用我的中文音频+文本做一个能说中文的声音"：

1. **先做对齐**：用 MFA 把音频切成短句并生成 `metadata.txt`（你工作区里已有 `montreal-forced-aligner`，可直接用）。
2. **优先用微调而非从头训练**：下载 `tts_models/multilingual/multi-dataset/xtts_v2`，在你对齐好的中文数据上 fine-tune，命令形如：
   ```bash
   CUDA_VISIBLE_DEVICES="0" python TTS/bin/train_tts.py \
       --config_path <xtts_v2_config.json> \
       --restore_path <xtts_v2_model.pth>
   ```
   或在 `recipes/` 下仿照 `ljspeech` / `multilingual` 的脚本写自定义训练脚本（设置 `formatter` 指向你的 `metadata.txt`，`language="zh-cn"`）。
3. **只想快速听效果**：先用 ⓍTTS 声音克隆（推理，不训练）：
   ```python
   tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2")
   tts.tts_to_file(text="你好世界", speaker_wav="你的参考.wav", language="zh-cn", file_path="out.wav")
   ```

## 一句话总结

**这个项目完全支持中文/英文的训练与微调，不需要自己写模型代码；真正的"特殊前置条件"是：① 音频和文本必须逐句对齐成标准数据集，② 需要 Python 3.9–3.11 + GPU 环境，③ 中文音素化器虽内置但标注为待校验，建议结合 espeak-ng 或 MMS 中文模型。** 如果你只是想用自己的声音说中文，最省事的是 ⓍTTS 微调（约 1–2 小时数据）；从头训练则需要大量数据与算力。
